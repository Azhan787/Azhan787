## 👨‍💻 About Me

Hello! I'm **Muhammad Azhan**, a web developer and second-year student passionate about creating modern, responsive, and user-friendly digital experiences.

I enjoy turning ideas into functional websites, exploring new technologies, and improving my development skills through hands-on projects. My current focus is frontend development, with a growing interest in backend engineering and full-stack application development.

I believe great web development is more than writing code. It's about understanding users, solving real problems, building accessible interfaces, and creating experiences that feel intuitive and polished.

- 🎓 **Currently:** Second-year student and developer.
- 💻 **Focus:** Frontend development and modern web experiences.
- 🚀 **Learning:** Full-stack development, application architecture, and backend technologies.
- 🎨 **Interests:** UI/UX design, interactive interfaces, dashboards, and creative web experiences.
- 🌍 **Goal:** Build useful digital products and collaborate with clients and developers worldwide.
- 📚 **Mindset:** Learn continuously, build consistently, and improve with every project.
